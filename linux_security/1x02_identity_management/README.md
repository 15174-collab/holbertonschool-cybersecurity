Learning Objectives

By the end of this project, you will be able to explain to anyone, without the help of Google:
Identity Fundamentals

    The /etc/passwd structure - What each field means and why UID 0 is special

    The /etc/shadow structure - Password hash formats and what $, $, $ indicate

    Service vs. human accounts - Why UIDs below 1000 should never have login shells

Privilege Management

    Dangerous groups - Why docker, disk, and shadow membership equals root

    Sudoers syntax - How to grant granular permissions without giving away the kingdom

    The NOPASSWD trap - Why convenience creates critical vulnerabilities

Authentication Hardening

    SSH configuration - Disabling password auth, enforcing key-based access

    PAM (Pluggable Authentication Modules) - Enforcing password complexity and lockout policies

    Passwordless onboarding - Creating accounts that never have a password to steal
